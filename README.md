# Кино в Нетании

Личное приложение для отслеживания того, что идёт в **Cinema City Netanya**
на ближайших выходных (пятница и суббота), с возможностью смотреть любые
другие даты.

## Зачем

Сайт Cinema City показывает расписание неудобно: только на иврите, по одному
дню, без оригинальных названий, страны и года, без рейтингов. Хочется одним
взглядом понять: какие фильмы идут в выходные, в какое время, в Prime или
в обычном зале, на каком языке, и что это вообще за фильм.

## Что умеет (цель)

- **Расписание на дату или на выходные.** Для каждого сеанса: время, фильм,
  зал (Prime или пусто), язык показа.
- **Карточка фильма.** Английское и оригинальное название, название на иврите, год,
  страна, язык оригинала, жанр, длительность, возрастное ограничение,
  дата премьеры в Израиле, краткое описание.
- **Заметки.** Что уже посмотрели, оценка, впечатления; в расписании
  такие фильмы отмечены `✓ watched`.
- **Рейтинги и деньги:** IMDb, Rotten Tomatoes (критики и зрители), бюджет и сборы.
- **Позже:** актёры и режиссёры,
  трейлеры, фильтры («только Prime», «без дубляжа»,
  «после 19:00»), история показов, сравнение с другими кинотеатрами.

## Как устроено

Три слоя, каждый можно менять независимо:

1. **Сбор.** Скрипт забирает данные у Cinema City (и позже у внешних
   источников вроде TMDB) и складывает в локальные файлы.
2. **Хранение.** Обычные Markdown-файлы с YAML-шапкой: читаются глазами,
   правятся руками, лежат в git. Два вида файлов: **фильм** и **день**.
3. **Визуализация.** Статическая HTML-страница, собранная из этих файлов.
   Сначала открывается локально, потом становится сайтом.

Подробный план по этапам в [PLAN.md](PLAN.md).

## Источник данных

У сайта cinema-city.co.il есть внутренние JSON-эндпоинты, которыми пользуется
его собственный интерфейс. Проверено 25.09.2026:

| Запрос | Что отдаёт |
|---|---|
| `GET /tickets/GetDatesByTheater?theaterId=5` | Список дат, на которые есть расписание |
| `GET /tickets/GetVenueTypesByTheater?theaterId=5` | Типы залов: `1` = רגיל (обычный), `4` = Prime |
| `GET /tickets/Events?TheatreId=1176&VenueTypeId=4&MovieId=0&Date=26/09/2026` | Фильмы и сеансы на дату для типа зала |
| `GET /tickets/Movies` | Все фильмы в прокате: `MovieId`, `Name`, `ExportCode` |
| `GET /movie/{MovieId}` (HTML) | Название иврит/английский, жанр, длительность, премьера, возраст, описание |

Идентификаторы Нетании: `ID=5` (обычные залы), `ID=24` (Prime),
`TixTheatreId=1176` (общий для обоих).

**Все данные хранятся на английском.** Русских названий нет.

**Язык показа** это язык звуковой дорожки в зале: `dubbed` (дубляж на
иврит, суффикс `-מדובב`), изредка `dubbed (Russian)` (`-מדובב לרוסית`),
иначе основной язык фильма по TMDB, а остальные его языки в скобках:
`English (+Hungarian, Italian)`. Эти куски в Израиле идут с ивритскими
субтитрами. `Hebrew` и `dubbed` это разные значения: первое значит
израильский фильм в оригинале, второе значит иностранный фильм
с ивритской озвучкой.

**Чего у Cinema City нет:** страны, года, оригинального языка, актёров,
рейтингов. Это берём из других источников:

| Что | Откуда |
|---|---|
| Английское и оригинальное название, год, страна, языки, жанры, описание | TMDB API, поиск по названию |
| Бюджет и мировые сборы (`budget_usd`, `revenue_usd`) | TMDB; у новых и небольших фильмов часто пусто |
| Рейтинг IMDb и число голосов | официальный файл IMDb `title.ratings.tsv.gz` (datasets.imdbws.com), кэш в `data/cache/`, перекачивается раз в сутки. Сам сайт IMDb скрипты не пускает |
| Rotten Tomatoes: критики (Tomatometer) и зрители (Popcornmeter) | страница фильма на rottentomatoes.com, найденная поиском по названию и году |

Рейтинги и деньги меняются, поэтому обновляются при каждом сборе;
остальная карточка создаётся один раз.

Доступ к TMDB хранится в `.env` (`TMDB_READ_TOKEN`,
запасной вариант `TMDB_API_KEY`), файл в `.gitignore`.

## Как пользоваться

```
python3 scripts/fetch_schedule.py              # ближайшие выходные (пт + сб)
python3 scripts/fetch_schedule.py 2026-10-02   # конкретные даты
python3 scripts/fetch_movie.py 6123 --refresh  # пересобрать карточку фильма
python3 scripts/fetch_ratings.py               # обновить рейтинги во всех карточках
python3 scripts/build_site.py                  # пересобрать только страницу
```

Результат открывать в браузере: `site/index.html`. Страница пересобирается
автоматически в конце `fetch_schedule.py`; шаблон в `scripts/site_template.html`.

Нужен только Python 3, внешних пакетов нет. Карточки фильмов создаются
один раз и потом не перезаписываются (кроме списка версий), так что
ручные правки в них сохраняются. Карточки с `needs_review: true`
сопоставлены с TMDB неуверенно, их надо проверить.

```
Movies/
├── README.md          описание (этот файл)
├── PLAN.md            план работ и статус
├── CLAUDE.md          правила проекта для Claude
├── data/
│   ├── movies/        один файл на фильм:  spiderman-brand-new-day-2026.md
│   ├── days/          один файл на день:    2026-09-26.md
│   └── watched.md     мои заметки: что посмотрели и оценки
├── scripts/           сбор и обновление данных
└── site/              визуализация
```
